# 역사 패널 사서 필터 검증

사서 선택 → `/api/source-records` → MongoDB `source_records` → 목록과 본문 표시 흐름을 확인했다. 운영 DB는 읽기만 했고, 수정한 패널과 실제 API 핸들러를 localhost의 독립 미리보기에서 실행했다. 지도 본체 대신 연도 변경 표시를 사용했으며 운영 사이트 배포는 수행하지 않았다.

- 기본 `전체 · 현재 연도`는 기존 연구 기록·원전 사료·중국 25사 묶음을 유지한다.
- 선택한 사서는 현재 지도 연도와 무관하게 전체 시대를 조회하며, 페이지당 목록 50건만 가져온다. 본문은 선택한 기사의 단건 API로 조회한다.
- 출처는 완전 일치로 비교해 원사와 신원사 같은 유사 이름을 섞지 않는다.
- 검색과 연도 미상 조건은 선택한 사서 안에서 함께 적용된다.
- 원사 실제 61건: 첫 페이지 50건, 다음 페이지 11건 확인. 두 번째 페이지 첫 기사에서 이전 기사로 이동하면 첫 페이지 마지막 기사로 돌아오는 것을 확인했다.
- 원사에서 `耽羅` 검색 결과 7건이 모두 원사 출처임을 확인했다.
- 원사의 연도 미상 필터 결과 4건 모두 연도 미상 표시를 확인했다.
- 전체 선택으로 돌아오면 현재 지도 연도인 1279년의 기존 연도별 화면이 복원되는 것을 확인했다.
- 고려사 24,599건에서도 전체 본문 대신 첫 50건만 조회되는 것을 확인했다.
- 브라우저 오류·경고 없음. 조회 API의 응답 상태는 모두 200이었다.
- 관련 Node 테스트 38개 통과. 출처 완전 일치, 페이지 조회, 검색 조건 교집합, 사서 전환 시 오래된 응답 무시, 전체 선택 복귀와 기존 화면 회귀 검증을 포함한다.

`preview.jpg`는 최종 원사 필터와 1218년 기사 열람 화면이다.
